Prioritise long-term human maintainability.

## File Management.

- Basic file structure:
  - /common/ - Contains all config files, preferably as either JSON or JSON5.
    - /common/<category_key>/
  - /core/framework - Contains clientside business logic.
  - /core/server - Contains backend business logic.
  - /core/ui/ - Contains frontend code.
    - /core/ui/components/ - Contains composable components used in UI files.
    - /core/ui/<interface_key>/
      - bottombar/ - UI anchored bottom.
      - leftbar/ - UI anchored left.
      - map/ - UI attached to the map/scene.
      - rightbar/ - UI anchored right.
      - topbar/ - UI anchored top.
  - /docs/ - Autogenerated docs for the current project.
  - /histmap/ - Data pipeline scripts for non-real time data.
  - /livemap/ - Data pipeline scripts for real-time data.
  - /localisation/ - Localisation strings.
  - /tests/ - Temporary testing files.
  - autobuild.bat/autobuild.sh - Builds program for distribution.
  - autodoc.bat/autodoc.sh - Produces documentation.
  - autorun.bat/autorun.sh - Starts the current program.
- All files should be snake_case.<extension>. The only exception are class files, which  are CamelCase.<extension>.
- Do not repeat yourself (DRY). Two or more, use a function or a for. If something is a config, ensure it exists in the /common/ folder.
- Files not mentioned or used anywhere should be deleted unless they exist for API/pipeline purposes.
- Files should not exceed 1000LOC in length. If they do, split it  into multiple files logically.
- If logical flow must be strongly preserved, like in data processing pipelines, it is recommended to prefix each step with a letter, i.e. A\_<function_key>, etc.
- Your files should be compatible with either JSDoc or Doxygen.

## Writing.

Use non-Oxford British English (EN-GB). Ensure that all human-readable strings are properly localised into British English, French, and German with language settings, variable delimiters in localisation use the £ sign, i.e. £1£. Timezones are GMT+0.

Numbers should use European decimals: 58,88. Use semantic abbreviations for numbers: k, M, B, T.
